# Connected Demand — The Hidden Link Between Paid Social and PPC

Source files for the Slides deck published at
https://claude.ai/artifact/BecPsECj75uSSrsctUCes2 (pulled 2026-09-26).

- `project/deck.json` — deck title, slide order (35 slides), sections and fonts
- `project/slides/*.html` — one file per slide; speaker notes are in each `<aside>`
- `assets/` — images, logos and the Satoshi font the slides reference

Slides reference assets as `/_blob/<id>`; the matching file is `assets/<id>.<ext>`.
The Slides app runtime (`artifact-type/`) is not included — it belongs to the artifact type, not the deck.
